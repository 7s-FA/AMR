# 조립대 도킹 설정 복구 — 2026-10-20

사용자 요청으로 오늘 추가한 **30cm 정렬 제한을 철회**했다. M1·M2 모두 해당 변경 직전 도킹 코드와 설정으로 복구했다.

- M1 조립대 정렬 목표: 기존 0.22m로 복구.
- M2 조립대 정렬 목표: 기존 0.20m로 복구. B2 설정 생성기도 복구.
- 정렬하면서 전진·회전하는 기존 접근 방식 유지. 30cm 경계 전진 차단 및 `staging_lateral_alignment_required` 즉시 실패 로직 제거.
- 기존 최종 정렬 확인, 시간·거리 제한, 엔코더 정지 제어는 원래대로 유지.
- 자재창고·주차·대기장소 및 방향 허용오차 변경 없음.
- 웨이포인트 아래 1cm 이동만 유지: M1 way3 Y = -0.203328193, M2 way3 Y = -0.218328193. X와 yaw는 그대로.

실제 로봇에 설치됐던 엔코더 코드의 변경 전 사본을 복원했으며, 구버전 로컬 IR 제어 파일로 덮어쓰지 않았다. 적용 시 이동 잠금·실시간 정지를 확인하고 도킹 대기 서비스만 재생성했다. 이동·토크·초기 위치 명령은 발행하지 않았고 실패 주문도 초기화하지 않았다.

로컬 저장소에서도 30cm 전용 구현과 테스트를 제거했다. 그 이전부터 있던 주행 개선과 방향 보정 변경은 유지했다. 관련 기존 제어·복구·경로 테스트 63개와 diff 검사가 통과했다.

변경 전/후 원본 및 철회한 패치·문서는 호스트 `.runtime/diagnostics/assembly-staging-*`와 `assembly-staging-local-rollback-20261020`에 보관한다. 실제 도킹 주행 시험은 수행하지 않았다.
